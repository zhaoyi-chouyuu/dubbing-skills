# 短剧文字规范 (短剧翻译本地化与字幕合规排版全流程规范)

本技能依据最新的短剧字幕合规标准与排版规范构建，覆盖短剧文字内容在**“前期翻译与本地化”**、**“配音后字幕格式整理与合规排版”**以及**“交付前合规性质检”**全生命周期中的标准要求。

---

## ⚠ 核心红线准则

1. **严禁纯机翻（MT）**：一经发现纯机翻痕迹，整剧立即打回并终止合作。
2. **人名与核心剧情保护**：无论字符数如何受限，**人名、主要动作、核心剧情词绝对严禁省略**。
3. **省译边界**：单句省略信息量不得超过原意的 30%；整集出现 3 处及以上大幅省译退回重改；字数与时长充足时，严禁擅自删减台词剧情。
4. **标点符号全面半角化**：除英文/外来人名中的全角中点「・」外，字幕正文所有标点**一律必须为半角**。**对白末尾严禁句号（「。」或「.」）**、**句中严禁逗号与顿号（「、」「，」「,」）**（需要停顿处用单个半角空格代替）、**问感号强制半角「?」「!」**（严禁全角「？」「！」及多重叠用「!?」「!!」）、**省略号强制3个ASCII点「...」**（计3字符，严禁单字「…」）、**引用必须用半角直角括号「｢｣」**（严禁全角「」『』）、**字幕正文严禁使用圆括号「（）」**（括号仅限画面字人名注音）、**假名长音符「ー」(U+30FC)必须保持全角**（严禁误打为全角破折号「―」或半角长音「ｰ」）。
5. **行宽与字符上限硬约束**：
   - 每行显示字符数**必须严格小于 12 个字符**（strictly below 12 characters，即**单行最多 11 个字符**；行达到 12 字符时必须进行语义断行，哪怕第 12 个字符是末尾标点也必须换行）。
   - 一条字幕**最多不超过 2 行**（绝对禁止 3 行）。
   - 单条字幕总显示字符数**最多不超过 22 个字符**（空格、标点、字母、前缀等均计入字符）。
   - 双人对话每行以**半角减号紧接台词开头，中间严禁空格**（`-台词`，严禁 `- 台词`）。
   - 语速标准：**CPS ≤ 20** 为标准达标，**CPS 20~29** 记为例外，**CPS ≥ 30 强制拦截打回**。

## 模式 A：台本翻译与本地化规范

执行短剧翻译、润色及人物设定时，严格遵守以下规范（详见 [翻译核心准则](references/translation-localization-rules.md) 与 [人名与词汇表](references/character-naming-glossary.md)）：

### 1. 剧集宣发三件套
* **剧名（意译/重写）**：不拘泥原文，根据题材爽点重写。参考日本主流三大形态：
  * 主副标题型：`「偽りの令嬢と泥棒システム〜私の人生を盗んだのは誰？〜」`
  * 口语台词型：`「うちのお嬢様はがり勉！」`
  * 制造悬念型：`「親友のパパは運命の番！？」`
* **简介（120~150 词）**：结构为 `[主角身份 + 核心冲突] + [悬念抛出/情感钩子]`。
* **社媒分享文案（50 词内单句）**：悬念型、反转型、情感型或爽点型强钩子口语短句。

### 2. 人名与改名三大硬规则（中译日）
* **汉字输入法兼容**：必须是日语输入法可打出的汉字（打不出的一律换异体字或相似字，如 `李婳` → `李画`）。
* **叠字简化**：叠字名一律简化为单字（如 `陈思思` → `陳思`）。
* **怪异发音与谐音脏话必须改名**：如原文 `陈虎` 日语音读类似 *chinko*（下流词），**必须改名为安全汉字 `陳豹`（√）**。
* **英文人名**：使用片假名音译，姓与名间加中点（`リース・フォスター`）。

### 3. 画面字人名首次注音
* **仅首次登场注音**：只有角色首次出场的画面字注音，非首次出现的画面字一律不注音。
* **拼音读音（ピンイン読み）**：假名必须还原中文普通话读音，严禁用日语音读。
* **格式**：姓与名加中点，且**全剧只有画面字注音允许使用括号「（）」**。
  ```text
  蘇建国（スー・ジエングオ）
  蘇婉の父
  ```

### 4. 称谓地道化避坑
* 严禁中文习惯机械直译：
  * `老婆` → **直接叫名字（○○）**（严禁直译 `妻よ`）
  * `阿强` → **強 / 強さん**（严禁直译 `ア強`）
  * `东子` → **東 / 東ちゃん**（严禁男角色译为女名倾向的 `東子`）
  * `余老` → **余先生 / 余様**（严禁直译 `余老`）
  * `三少 / 三小姐` → **○○様 / 若様 / お嬢様**
  * `苏校花` → **蘇さん / 蘇様**

### 5. 核心热词地道映射
* `打脸` → **見返す**（严禁直译 `顔を叩く`）
* `逆袭` → **成り上がる / 逆転する**（避免直接照搬 `逆襲`）
* `战神 / 龙王` → **最強の戦士 / 最強の男**
* `白月光` → **忘れられない人 / 初恋の人**（严禁直译 `白い月光`）
* `普信男` → **勘違い男 / 痛い男**
* `净身出户` → **一文無しで家を出る / 手ぶらで出て行く**
* `三十年河东三十年河西` → **世の中は変わるものだ**

### 6. 角色人设台词风格
* **霸总**：短句、祈使命令、冷峻权威（「しろ」「黙れ」「やめろ」）。
* **弱势**：柔和、疑问句、多语气助词（「私なんか…」「〜かな」）。
* **反派**：讥讽、反问、冷嘲热讽（「残念だったわね」「まさか本気？」）。
* **小人物**：口语生活化、俚语口头禅（「マジ？」「やばい」「じゃん」）。
* **古装角色**：严格区分尊卑，敬语谦逊语规范（「仰せのままに」「万死に値します」）。

## 模式 B：字幕排版与技术格式规范 (Compliance 标准)

处理字幕排版或配音后字幕合规修正时，严格执行以下技术参数（详见 [字幕格式规范](references/subtitle-format-requirements.md) 与 [语义断行案例库](references/semantic-linebreak-cases.md)）：

### 1. 标点符号硬性规范 (全面半角化)
* **视觉洁净原则**：在不损伤句子原意、发话者意图和可读性的前提下，优先精简多余标点。
* **标点全面半角化**：**除英文/外来人名中的全角中点「・」（如 `シェフ・ルーカス`）允许保留外，所有保留的标点必须为半角**。严禁在最终字幕中残留全角 `？`、`！`、`，`、`。`、`、`、`「」`、`『』`、`…`。
* **句号**：对白末尾**绝对禁止**句号（无论全角 `。` 还是半角 `.` 均必须删除）。
* **逗号/顿号**：句中**绝对禁止**任何逗号（`、`、`，`、`,`）。需要停顿或分隔时用**单个半角空格**，无需停顿时直接相连。
* **问号与感叹号**：强制使用**半角 `?` 与 `!`**。仅在表达真实疑问或强烈情绪时保留，删除冗余装饰性标点，严禁 `!?`、`!!`、`??` 等叠用。
* **省略号**：能省则省；确实不可缺少时，统一为 **3 个 ASCII 半角点 `...`**（计 3 个显示字符），**严禁使用单字全角 `…`**、双省略号 `……` 或句号点 `．．．`。
* **引号/括号**：无语义价值时直接删除；必要引用时使用**半角直角括号 `｢｣`**（U+FF62, U+FF63），严禁使用全角 `「」` 或英文引号 `""`。
* **圆括号**：**字幕正文（含内心独白）绝对禁用任何括号 `（）`**，括号仅限画面字人名首次注音使用。
* **假名长音符「ー」防混淆保护**：片假名长音符 `ー`（U+30FC）是日语固有拼写，**必须保持全角**！严禁转为减号 `-` 或半角长音 `ｰ`，严禁误打为全角破折号 `―`（U+2015）或长横 `—`（如 `サイコ―!` 必须修正为 `サイコー!`）。

### 2. 双人对话同轴格式
当一条字幕内有两位说话者时，每行开头必须使用**半角减号紧接台词，中间严禁空格**（`-台词`）：
```text
-先に行って
-すぐ追いつく
```
*注：严禁使用带空格的 `- 台词`、`=台词` 或全角破折号。若两人异口同声说出完全相同台词，仅保留一句且不加横杠。*

### 3. 单行字符上限（严格 < 12 字符）与总宽度约束
* **单行显示字符数严格小于 12 字符（strictly below 12 characters）**：
  * **单行最大显示字符数 ≤ 11 个字符**；
  * 行达到 12 字符时必须进行语义换行（即使第 12 个字符是末尾标点也必须换行）。
  * 空格、半角标点（如 `?`、`!`，`...` 计 3 字符）、数字、英文、双人前缀 `-` 均全数计入字符数。
* **最大行数**：一条字幕**最多 2 行**（绝对禁止 3 行）。
* **单条总字符数**：单条字幕总显示字符数**最多不超过 22 个字符**（2行 × 11字）。
* **超长密集台词处理**：若源台词极度密集超长，应在前期剧本/Excel 阶段于自然气口处拆分成两条前后相接、不重叠的独立短时轴，严禁强塞为 3 行字幕。

### 4. 语义断行受保护单元与双行上下视觉平衡 (Two-line Balance)
换行必须以语法语义完整性为最高准则，严禁切断以下结构：
* 活用词干与词尾（严禁腰斩单词）；
* 片假名专有名词、人名、数量词（如 `1回戦`）；
* 复合助词（如 `でも`）；
* 补助动词与固定搭配（`ている`, `ていく`, `てくる`, `てしまう`, `てみる`, `てください`, `なければ`, `なくなる` 等）；
* 严禁产生仅 1~2 字符的孤立碎行（如行首单独留下一个助词或逗号）。
* **双行上下视觉平衡审查 (Two-line Balance Review)**：
  * 在保证语法语义安全的前提下，必须对双行断点进行视觉均衡审查；
  * 优先选择上下两行字数更接近、视觉重构更稳定的合法断点，避免极端悬殊的排版。
  * *对比示例*：
    * ❌ 避免不均衡断句：
      ```text
      ゾンビの
      軍隊を作る気だわ
      ```
    * ✅ 优先均衡断句：
      ```text
      ゾンビの軍隊を
      作る気だわ
      ```

### 5. 阿拉伯数字半角化
* 独立或计数的阿拉伯数字一律使用半角 ASCII `0–9`，严禁全角 `０–９`。
* 转换时仅对数字字符做映射（`０１２３４５６７８９` → `0123456789`），禁止全串 NFKC（避免破坏假名与排版）。
* 汉字数字（如 `一人`、`二度目`）保持原样。

### 6. 语义空格审查 (Semantic Whitespace)
* 日语不使用分词空格，严禁为了字数对齐或机械分词插入空格。
* 仅在两个独立发话、明确停顿（替代逗号）处保留单个半角空格。
* 消除词内、复合词组、修饰语与中心语之间的多余空格（如 `呆れるほど か弱いけど` → `呆れるほどか弱いけど`）。
* 严禁行首、行尾留有空格，严禁连续两个半角空格。

## 模式 C：语速 (CPS) 控制与自动化质检

### 1. CPS 控制指标 (合规标准)
* **标准目标（达标）**：**CPS ≤ 20**。
* **允许偶发（记为例外）**：**CPS 20 ~ 29**。
* **严重违规拦截（阻断打回）**：**CPS ≥ 30 强制拦截打回！**

### 2. 自动化质检脚本运行
使用内置脚本对导出的 `.srt` 或 `.ass` 运行格式与合规性审查：

本 skill 不运行声学模型，不会从 GPU 获益。直接使用 Windows Python 可避免 WSL 挂载盘的小文件读写开销；它与另外两个 skill 的 WSL GPU 运行方式可以同时使用。

```powershell
$PYTHON = 'E:\AI_Models\envs\windows\speaker-evidence312\Scripts\python.exe'
$SKILL_DIR = 'C:\Users\zhao-\.claude\skills\shortdrama-text-standards'

# 全量字幕合规质检（严格执行<12字符、半角标点、双人无空格横杠检查）
& $PYTHON "$SKILL_DIR\scripts\audit_subtitles.py" <字幕目录> --report <字幕质检报告.csv>

# 遇到阻断错误直接抛出返回码
& $PYTHON "$SKILL_DIR\scripts\audit_subtitles.py" <字幕目录> --report <字幕质检报告.csv> --fail-on-error

# 专项：假名长音符 vs 破折号防混淆检测
& $PYTHON "$SKILL_DIR\scripts\audit_kana_marks.py" <字幕目录>

# 专项：数字宽度回归单元测试
& $PYTHON "$SKILL_DIR\scripts\test_digit_width_regression.py"
```

脚本将自动审查：
1. 单行显示字符数达到或超过 12 字符（严格要求 < 12）；
2. 单条总字符数超过 22 字符，或超过 2 行；
3. 全角标点残留（全角 `？`、`！`、`「」`、`『』`、`…`、`，`、`。`、`、`）；
4. 句尾句号残留、句中逗号未转空格；
5. 双人对白横杠格式错误（如带有空格 `- 台词` 或非减号前缀）；
6. 省略号未使用 3 个 ASCII 点 `...`；
7. 全角阿拉伯数字 `０–９`；
8. 假名长音符误用全角破折号 `―` 或减号 `-`；
9. 语法断行受保护单元切断、行首 1~2 字符孤行；
10. CPS ≥ 30 阻断警告。
