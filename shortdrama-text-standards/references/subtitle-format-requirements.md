# 短剧字幕技术格式与合规排版规范 (Subtitle Format Requirements)

本参考规范整理自最新的短剧字幕合规标准（Compliance v1.2.0），是短剧字幕翻译输出、配音后字幕排版修正与交付验收的硬性技术格式标准。

---

## 一、 标点符号硬性规范 (全面半角化)

除英文/外来人名中的全角中点「・」外，字幕正文中所有保留的标点符号**一律必须为半角**。严禁在成品字幕中残留任何全角标点：

| 标点类别 | 规范要求 | 错误示例 / 严禁用法 | 正确规范示例 | 规则要点说明 |
| :--- | :--- | :--- | :--- | :--- |
| **句号** | **一律删除** | `愛している。` / `愛している.` | `愛している` | 对白末尾绝不留句号（无论全角「。」还是半角「.」） |
| **逗号/顿号** | **一律禁止，用半角空格代替** | `待って、行かないで` / `待って，行かないで` | `待って 行かないで` | 句中严禁「、」「，」「,」；需停顿用单个半角空格，无需停顿直接相连 |
| **问号** | **强制半角「?」** | `本当ですか？` / `本当ですか？？` | `本当ですか?` | 严禁全角「？」；真实疑问才用，严禁连续堆叠 |
| **感叹号** | **强制半角「!」** | `逃げろ！` / `何だと！？` | `逃げろ!` | 严禁全角「！」；强烈情感才用，严禁「!?」「!!」堆叠 |
| **省略号** | **统一为3个半角点「...」** | `待って…` / `待って……` / `待って．．．` | `待って...` | 严禁单字全角「…」或双全角「……」，计为3个显示字符 |
| **引号** | **统一为半角直角括号「｢｣」** | `「約束だ」` / `“約束だ”` / `"約束だ"` | `｢約束だ｣` | 无语义必要直接删除；必要时必须用半角直角括号 U+FF62/U+FF63 |
| **圆括号** | **字幕正文绝对禁用「（）」** | `（俺はどうすれば…）` | `俺はどうすれば...` | 正文绝对禁用括号（内心独白亦禁用）；**仅限画面字人名首次注音** |
| **中点** | **仅外来人名保留全角「・」** | `シェフ・ルーカス`（√） | `シェフ・ルーカス` | **全剧唯一允许全角标点处**；非外来人名禁止滥用 |
| **假名长音符**| **片假名长音「ー」必须保持全角** | `サイコ―!`（误用破折号 U+2015） / `サイコｰ!` | `サイコー!` (U+30FC) | 属于假名拼写而非标点，严禁转为减号 `-` 或误打为破折号 `―` |

## 二、 屏幕排版与字符上限（严格小于 12 字符）

### 1. 字符计算规则
* 无论是日文假名、汉字、英文、数字、空格、半角标点（如 `?`、`!`，`...` 计 3 字符）、还是双人前缀 `-`，**全数按实际显示字符数（Visual Displayed Characters）严格计数**。

### 2. 行宽与行数上限
| 排版维度 | 硬性约束标准 | 超标处理原则 |
| :--- | :--- | :--- |
| **单行字符数** | **严格小于 12 字符（strictly below 12 characters）**<br>即**单行最多 11 个显示字符** | 行达到 12 字符时必须进行语义断行；**即使第 12 个字符是末尾标点（如 ? / ! / ...）也必须换行** |
| **单条最大行数** | **最多不超过 2 行** | 绝对严禁出现 3 行字幕 |
| **单条总字符数** | **最多不超过 22 个显示字符** (2行 × 11字) | 超出 22 字符必须在前期剧本阶段拆为前后相接的两条时轴 |

### 3. 超长密集台词 upstream 拆分原则
若源台词信息量大、极其密集，在前期 Excel/剧本阶段就应根据语音自然停顿处，将一条超长轴拆分为连续不重叠的两条独立字幕轴：
```text
【原超长单条字幕】：みんなが君をマグロ処女と呼ばなくなるから?
【拆分为两条独立轴】：
Cue 1 (T0 → Ts):
みんなが君を
マグロ処女と

Cue 2 (Ts → T1):
呼ばなくなるから?
```

## 三、 双人对话同轴排版格式

同一条时间轴中包含两位说话者的对白时，采用半角减号紧接台词格式：

### 1. 格式要求（无空格横杠）
每行开头以半角减号紧跟台词，**中间严禁包含空格**：
```text
-先に行って
-すぐ追いつく
```
*(严禁使用带有空格的 `- 台词`、`=台词`、全角破折号 `―` 等)*

### 2. 异口同声处理
* 当两人或多人异口同声说出完全相同台词时，**仅保留一句台词，且去除横杠**。

## 四、 双行上下视觉平衡审查 (Two-line Balance)

在将字幕折为两行时，必须同时满足**语法语义完整性**与**上下行视觉平衡**：

1. **语义完整优先**：
   - 严禁腰斩词干词尾（如动词/形容词活用）；
   - 严禁切断专有名词、片假名人名、数词+量词（如 `1回戦`）；
   - 严禁切断复合助词（如 `でも`）；
   - 严禁切断补助动词与固定搭配（`ている`、`ていく`、`てくる`、`てしまう`、`てみる`、`てください`、`なければ`、`なくなる` 等）；
   - 严禁行首出现 1~2 字符的孤立碎词（如单个助词或逗号）。
2. **上下行视觉平衡**：
   - 在合法的语义断点中，优先选择上下行长度更为均衡的方案，避免极端不平衡的排版。
   - *标准示范*：
     - ❌ 避免不均衡：
       ```text
       ゾンビの
       軍隊を作る気だわ
       ```
     - ✅ 优先平衡：
       ```text
       ゾンビの軍隊を
       作る気だわ
       ```

## 五、 阿拉伯数字与语义空格审查

### 1. 数字半角化
* 阿拉伯数字一律使用半角 ASCII `0–9`，严禁全角 `０–９`（如 `100万円`、`1 2 3`、`第1回`）。
* 仅针对 `[０-９]` 字符映射转换，禁止整句 NFKC，汉字数字（`一人`、`二度目`）保持不变。

### 2. 语义空格审查
* 日语不是分词语言，严禁为了字数凑整或词性标注在词间加空格。
* 消除词内与修饰结构内部的错误多余空格（如 `呆れるほど か弱いけど` → `呆れるほどか弱いけど`）。
* 严禁行首、行尾空格及连续两个半角空格。

## 六、 语速控制（CPS 标准）

| 语速指标 | 标准值 | 说明 |
| :--- | :--- | :--- |
| **标准目标** | **CPS ≤ 20** | 观众阅读体验舒适 |
| **允许偶发** | **CPS 20 ~ 29** | 语速较快，作为例外登记 |
| **严重违规** | **CPS ≥ 30** | **强制拦截打回！必须精简措辞或调整时轴** |
