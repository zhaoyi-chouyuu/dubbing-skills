# 短剧翻译与本地化核心准则 (Translation & Localization Rules)

本参考规范整理自《CMS 日语短剧字幕翻译标准 v3.0》，全面规范短剧从宣发信息（剧名、简介、分享文案）到台词翻译、角色人设语气、增删省译与文化本地化的核心规则。

---

## ⚠ 顶级合作红线
**严禁出现任何形式的纯机翻（MT，Machine Translation）。一经质检发现，立刻打回整部剧集，并直接终止合作！**

---

## 一、 剧集信息翻译（宣发三件套）

翻译内容分为两大主体：**A. 剧集信息**（剧名、简介、分享文案）与 **B. 字幕 & 画面字**。宣发物料要求短平快、高吸引力、符合日本主流网生受众习惯。

### A-1 剧名翻译规范
日语剧名翻译**无需拘泥于原文**，严禁逐字直译，应更倾向于**基于核心爽点与人物冲突的意译或重写**。

#### 1. 按题材类型分类处理
* **霸总题材**：强调权势感与情感悬殊冲突，标题宜简短有力，突出阶层差距或命运反转。
* **狼人题材**：保留题材辨识度，`Luna` / `Alpha` / `Fate`（運命の番）等核心概念参考日本市场同类流行小说/漫改惯用译法。
* **男频题材（重生 / 系统 / 赘婿 / 战神）**：传递极致逆袭感和爽点，将“重生、打脸、系统、龙王”精准本地化。
* **修仙 / 玄幻**：功法、境界、门派名称全剧统一；东方意象根据目标受众接受度决定意译或保留。
* **古装 / 历史**：规避与日本文化产生歧义的词汇；朝代、官职、地名按规范处理，**严禁直译拼音**。

#### 2. 原剧名类型与本地化策略
* **直白型**（如《闪婚老公是豪门》《替身老婆不想演》）：直接本地化核心冲突词，确保“一读即懂、高点击率”。
* **悬念 / 反问型**（如《你以为我爱你？》）：保留悬念语气，使用日文反问/疑问句式。
* **意象 / 修辞型**（如《白月光归来》《凤凰涅槃》）：“白月光”、“凤凰”等具中国文化特异性的词汇严禁直译。

#### 3. 日本市场三大主流剧名形式（推荐参考）
* **形式一：主副标题型**
  * `「偽りの令嬢と泥棒システム〜私の人生を盗んだのは誰？〜」`
  * `「田舎娘の逆襲：私は太子妃になる！」`
* **形式二：口语·台词型**
  * `「うちのお嬢様はがり勉！」`
  * `「先生、僕と結婚してください」`
* **形式三：制造悬念型**
  * `「親友のパパは運命の番！？」`
  * `「初恋は偽装カノ」`
* *注：剧名须规避极端敏感词，`クソ` 等脏话在标题中谨慎使用。*

### A-2 简介翻译规范
简介为剧集核心卖点提炼，须在严格字符限制内建立强冲突。
* **字符数限制**：日语简介控制在 **120 词以内**，**最多不超过 150 词**（含空格与标点）。
* **内容原则**：原文冗长铺垫全部删去，仅保留：**核心剧情 + 主要角色关系 + 核心冲突**。
* **经典句式结构**：
  * **开场**：`[主角身份] + [核心冲突 / 命运转折]`
  * **结尾**：`[悬念抛出 / 情感钩子]`
* **官方推荐范例**：
  * *宫廷爽剧范例*：
    > 「目を覚ますとそこは古代の宮廷。……絶体絶命のどん底から、前代未聞の「寝そべり王」へと駆け上がっていく。」
  * *狼人恋爱范例*：
    > 「ライラは狼になれない落ちこぼれオメガ。……二人が禁断の触れ合いを持った時、真実が明らかになる……もしかして二人は運命の番！？」
  * *现代豪门反转范例*：
    > 「両親を失い、巨大グループの存続と己の命、その両方を狙われる美しき令嬢、姜梨。 ……そして、巨大な陰謀の先に、二人が見るものとは──」

### A-3 社媒分享文案规范
用于 TikTok、X (Twitter)、Instagram 等社交平台推广传播，强调短平快与高情绪张力。
* **字符数限制**：尽量控制在**一句话**，**最多不超过 50 词**（不含 hashtag）。
* **风格要求**：纯正口语化、极强情绪感染力，多用反问句、感叹句、悬念句，避免平铺直叙。
* **四大高点击句式范例**：
  * **悬念型**：「残酷な裏切りからの大逆転！絶望の底で差し伸べられた女社長の手は、救いか、それとも――」
  * **反转型**：「一文無しに嫁いだはずが……気づけば天下の皇后陛下に？」
  * **情感型**：「血と裏切りに試される、マフィアの愛。」
  * **爽点型**：「四年間支えた彼女に裏切られた男、逆襲して王となる！」

## 二、 台词翻译五大核心原则

### 1. 地道自然
* 译文必须符合日本短剧观众的听觉与阅读习惯。
* 灵活显化潜台词、合理调整说话方式与人称呼应，但必须完整保留情绪张力与压迫感，杜绝直译中文句式。

### 2. 简洁克制与从句规范
* 字幕以秒为单位播放，尽量避免繁复的定语从句或长从句堆叠：
  * **严禁**：两重及以上嵌套从句；
  * **严禁**：长度超过单条字幕一半的长定语从句；
  * **从句简化策略**：
    * *条件句*（if...）：改写为名词短语或直接陈述句；
    * *原因句*（because/since）：因果连词可省略，直接并列陈述结果与原因；
    * *让步句*（although...）：拆为两个短句，用破折号或接续词承接。

### 3. 用词精准与角色语气设定（防千人一面）
根据角色性格地位采用不同的用词与句尾助词，使角色立体鲜明：

| 角色类型 | 台词风格特征 | 推荐句式倾向 | 常见词汇 / 句尾示例 |
| :--- | :--- | :--- | :--- |
| **霸总 / 主导型** | 简短、命令式、冷峻权威 | 短句、祈使句、极少冗余解释 | 「しろ」「来い」「黙れ」「やめろ」 |
| **弱势 / 委屈型** | 柔和、犹豫、自我否定 | 疑问句、省略句、语气助词多 | 「私なんか…」「～かな」「～よね」 |
| **反派 / 讽刺型** | 讥讽、反问、轻蔑冷笑 | 反问句、双关修辞、轻描淡写 | 「残念だったわね」「それで？」「まさか本気？」 |
| **小人物 / 配角** | 口语化、生活化、朴实粗糙 | 俚语俗语、缩略语、流行口头禅 | 「マジ？」「やばい」「だろ？」「じゃん」 |
| **历史 / 古装角色** | 正式尊称、尊卑礼仪规范 | 固定礼仪用语、谦让语与敬语句式 | 「ただいま参ります」「万死に値します」「私めに」「仰せのままに」 |

### 4. 口语优先与「辞藻华丽」边界
* 优先使用日本口语常用词，非必要不堆砌生僻词汇或文学典故。
* **边界红线**：若观众需要暂停查词才能理解，则视为违规堆砌；一条字幕内叠加两个以上复杂修辞属于过度。
* **允许华丽的例外**：人物外貌特写描写、古风/诗歌/独白特定文学场景、明确的高贵文人/学者身份台词。

### 5. 通顺流畅与增删/省译边界
* **允许增加（可增）**：
  * 句子主谓结构补全（日语习惯省略但缺少会导致歧义时可补）；
  * 衔接词/自然语气词（如「だから」「つまり」），频率需克制；
  * 显化原文内涵潜台词（须有台词依据，严禁凭空编造剧情）。
* **允许删减（可删）**：
  * 无效口头填充词（如「那个…」「就是说」）；
  * 前后文已重复交代的信息；
  * 字幕字符超限时，**优先省略修饰性成分**。
* **绝对严禁的增删（红线）**：
  * ❌ **核心语义逆转**：如肯定变否定、反转因果、扭曲人物关系；
  * ❌ **大段省译**：单句省略信息量**不得超过原意 30%**；整集出现 3 处及以上大幅省译**直接退回打回**；
  * ❌ **无压力删减**：在字数和 CPS 充裕的情况下擅自删除剧情信息；
  * ❌ **核心剧情词删减**：**人名、主要动作、关键情节词绝对严禁省略**。

## 三、 文化与地域本地化标准

### 1. 货币与度量衡换算
* **货币处理**：
  * **中译日**：必须把**人民币换算成日元**（结合时代背景与购买力合理换算，不必每句都生硬带“円”，依据口语习惯自然表达）；
  * **英译日**：保留原文美元（ドル）。
* **度量衡**：长度、重量、温度若源语为英制或非标准制，须按日本公制习惯换算。

### 2. 地名与机构本地化
* **地名**：中国地名优先使用官方/通行译名（如 `广州` → `広州`）；虚拟虚构地名可合情合理本地化（如 `江城` → `浜市`）。
* **机构设施**：根据受众理解度适度归化（如 `民政局` → `市役所`）。古风历史剧中的特色机构宜保留文化特色，慎用现代归化。
* **常用软件/APP**：
  * 结合剧情画面，可意译为日本常用软件（如 `Line`、`Paypay`），也可使用国际通用名称（`WeChat`、`Alipay`）；
  * **红线**：画面若明确显示微博界面，严禁翻译为 `X` 等日本本地软件导致穿帮。

### 3. 数字与日期书写规范
* **数字 1 ~ 10**：在字符数允许时，优先使用日语**汉字**（一、二、三…十）；
* **数字 10 以上**：统一使用**半角阿拉伯数字**（如 `15`、`100`、`5000`）；在字符极其紧张时可灵活调整；
* **日期年代**：必须采用**半角阿拉伯数字**表达（如 `1980年代`、`21世紀`、`2004年6月3日`）。

### 4. 敬语前后一致性
* 同一人物在同一场景、面对同一谈话对象时，敬语水准必须保持绝对统一。
* 严禁出现前一句使用敬体后一句突然崩坏为粗鲁语气的现象（例：`社長、お呼びでしょうか。何の用だ？（×）`）。
