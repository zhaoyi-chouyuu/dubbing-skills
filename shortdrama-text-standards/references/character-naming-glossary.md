# 人名转写、称谓与术语本地化规范 (Character Naming & Glossary)

本参考规范整理自《CMS 日语短剧字幕翻译标准 v3.0》，详细规定了中英文人名转写、画面字注音、称谓避坑、常用俚语及敏感词处理标准。

---

## 一、 中文人名转写与改名红线（中译日）

中文人名在翻译为日文时，**不可随意拼音音译**，需直接转换为**日语汉字**，并严格遵守以下三大硬性规则：

### 1. 汉字输入法兼容原则
* **核心要求**：凡是日语输入法打不出来的汉字**一律不得使用**，防止视频压制、字幕系统或播放器缺字、乱码或显示为空白。
* **处理优先级**：
  1. 优先使用日语中的**异体字 / 新字体**；
  2. 若无对应异体字，替换为字形或含义**相似的日语汉字**。
* **标准示例**：
  * `陈屿` → `陳嶼`
  * `李婳` → `李画`（因“婳”在标准日文输入法中无法输入，替换为相似字“画”）

### 2. 叠字名简化原则
* **核心要求**：中文习惯中的叠字名（如思思、婷婷、晶晶），在日语语境中直译会显得非常生硬违和。**凡叠字名一律简化为单字**。
* **标准示例**：
  * `陈思思` → `陳思`
  * `刘婷婷` → `劉婷`

### 3. 规避怪异发音与谐音脏话（改名原则）
* **核心要求**：若人名按照日语音读发音非常奇怪、拗口，或者**谐音粗俗脏话/下流词汇**，**必须主动改名**！
* **经典案例（重要禁忌）**：
  * 原文：`陈虎`
  * 错误译法：`陳虎`（×）（“陳虎”日语音读发音类似 *chinko*，是日语男性生殖器/粗俗俚语，会引起严重投诉）
  * **推荐正确译法**：**`陳豹`（√）**（同属猛兽猛将意象，改名为发音正常且含义匹配的汉字）

### 4. 全剧一致性
* 角色一旦确定日语汉字写法，必须在全剧、分集字幕、画面字及人物设定表中**100% 保持一致**，严禁前后集不统一。

## 二、 英文人名转写（英译日）

* 原剧英文名**不进行本地化意译**，直接使用**片假名音译**。
* 姓名之间使用**中点「・」**隔开。
* 全剧必须保持统一音译。
* **标准示例**：
  * `Reese Foster` → `リース・フォスター`
  * `Dominic` → `ドミニク`

---

## 三、 画面字（屏幕字）人名注音规范

短剧中屏幕出现的角色介绍、身份卡等画面字，注音格式必须严格遵守：

1. **仅限首次登场注音**：
   * **仅在角色首次出场**的画面字中进行假名注音；
   * 汉字较多的特殊名词若必要可注音；
   * **非首次出现的画面字一律不再注音**。
2. **必须使用拼音读音（ピンイン読み），严禁日语音读**：
   * 画面字的假名注音必须还原**中文普通话发音**，严禁使用日式音读或训读。
3. **分隔符与括号格式**：
   * 姓与名之间用**中点「・」**隔开；
   * **全剧仅在画面字注音时允许使用全角括号「（）」**，字幕正文中严禁使用括号。
4. **官方标准示例**：
   ```text
   【原文画面字】
   苏建国
   苏婉的父亲

   【标准日文画面字】
   蘇建国（スー・ジエングオ）
   蘇婉の父
   ```

## 四、 称谓与尊称地道化清单

称谓必须根据说话人身份地位、场景关系做目标语本地化，严防生硬直译。

### 1. 称呼避坑对照表（PDF 第 6.1 节）

| 中文 / 英文原文 | 常见错误 / 严禁译法 | **推荐正确译法** | 避坑解析 |
| :--- | :--- | :--- | :--- |
| **老婆** | 妻よ | **直接叫名字（○○）** | 日语夫妻日常对话绝不会喊“妻よ”，应叫名字或昵称 |
| **阿强** | ア強 | **強 / 強さん** | 中文前缀“阿”不能音译成假名“ア”，应去除前缀并依关系加さん |
| **东子** | 東子 | **東 / 東ちゃん** | “~子”在日文中多为女性名，男性角色改用“~ちゃん”或名字 |
| **余老** | 余老 | **余先生 / 余様** | 日语中没有“姓+老”的尊称结构，依地位译为先生或様 |
| **三少 / 三小姐** | 三の若様 / 三のお嬢様 | **○○様 / 若様 / お嬢様** | 去除机械的“三之”，直接称呼“若様/お嬢様”或“名字+様” |
| **苏校花** | 蘇校花 / 蘇マドンナ | **蘇さん / 蘇様** | 严禁生造“校花”汉字，口语对话中自然称呼姓氏尊称 |
| **sweetheart** | あなた | **○○ちゃん** | 亲密称呼本地化 |

### 2. 正式尊称与职衔
* 格式：`[姓氏] + [目标语尊称]`（如：`李さん`、`李様`、`李殿`）。
* 职衔称呼：`李先生`、`李社長`、`王部長`。
* 严禁出现生造违和发音（如将“鬼少”直译为“鬼様”导致观众产生怪异观感）。

## 五、 短剧高频术语、俚语与热词对照表（PDF 第 3.2 节）

短剧特有的爽点热词，切忌字面直译，须用日本观众熟悉地道表达：

| 原文 | 常见错误 / 严禁直译 | **推荐地道译法** | 核心情绪与场景说明 |
| :--- | :--- | :--- | :--- |
| **打脸** | 顔を叩く | **見返す** | 爽点核心：用实力或真相让对方刮目相看 |
| **逆袭** | 逆襲 | **成り上がる / 逆転する** | 日语“逆襲”多偏向反击攻击，短剧底层翻盘应为“成り上がる” |
| **战神** | 戦神 | **最強の戦士** | 战神赘婿题材核心称谓 |
| **龙王** | 龍王 | **最強の男** | 龙王归来题材核心称谓 |
| **白月光** | 白い月光 | **忘れられない人 / 初恋の人** | 严禁直译“白色月光”，意译为心中无法取代的情感寄托 |
| **普信男** | 普通で自信のある男 | **勘違い男 / 痛い男** | 流行网络语本地化 |
| **老头** | ロートル（死語） | **ジジイ** | 避免使用昭和过时死语，用口语化自然表达 |
| **净身出户** | 身一つで家を出る / 財産なしで出る | **一文無しで家を出る / 手ぶらで出て行く** | 地道表达一无所有地被赶出家门 |
| **三十年河东三十年河西** | 三十年河の東、三十年河の西 | **世の中は変わるものだ** | 谚语严禁字面直译，传达世事无常、风水轮流转之意 |
| **树倒猢狲散** | 木が倒れると猿が散る | **勢いがなくなれば人も去る** | 传达权势倒塌后依附者散去之意 |
| **破镜重圆** | 割れた鏡が丸くなる等 | **（表达破裂后和好的惯用短句）** | 传达夫妻复合情意 |

## 六、 敏感词与脏话处理策略（PDF 第 3.2 节）

### 1. 政治、文化敏感词
* 一律谨慎采取**模糊或省略处理**，避免直接冒犯受众。
* *例：`棒子国` → `韓国 / K国`；`小日子` → `あいつら / あの連中`*。

### 2. 脏话粗口四阶处理法
根据说话人性格身份、场景冲突激烈程度灵活选择，**切忌全剧千篇一律**：
1. **直接翻译**：在观众接受度内保留情绪冲击力。（例：`Damn it!` → `「クソ！」`）
2. **委婉替代**：采用温和表达避免极端冒犯。（例：`Shit!` → `「やばい!」`）
3. **情绪省略**：不影响核心信息时精简。（例：`What the hell are you doing?` → `「何すんの?」`）
4. **文化适应**：地道日式口语情绪爆发。（例：`Bloody hell!` → `「ふざけんなよ！」`）

---

## 七、 核心信息保护红线

在因字幕字符或 CPS 超标需要进行精简（省译）时：
* 优先省略修饰语、语气填充词；
* **人名、称谓、主要动作、关键剧情推进词绝对严禁省略！**
