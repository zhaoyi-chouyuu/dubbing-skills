# 短剧配音逐句剪辑与合成

## 工作对象与唯一完成标准

来料始终是**按角色分开的待剪录音**。已完成的视频/原声用于核对剧情、人物轮次和重叠；最终审核台本（没有时用经确认的字幕）提供每句内容、角色和目标开始时间。已剪好的成品音频不是本 skill 的剪辑 mode。

**三种 mode 只决定如何找出每句的源录音，后续剪辑规则完全相同。** 一集“剪完”意味着每条目标台词均找到实际念出的内容，保住完整发声，并逐句核对最终真实发声开头：通常等于台本/字幕开始码；若被前句占用，记录必要顺延及原因；一有空档即回到下一句原定时间。不能以整条音频大致对位、混合成功或文件格式正确代替逐句验收。

## 三种来料 mode：只区分找句方法

| mode | 来料状态 | 找出每句源录音的方法 |
| --- | --- | --- |
| 1. 跨集长条、粗对位 | 每角色一条约覆盖多集；原位置大致接近，但不精确 | 结合台本内容和粗时间确认集界，只在安全静音处分集；每集每角色音轨先建立 `mix-aligned` 粗对位基线，再对照实际内容逐句确认和精修。 |
| 2. 单集短条、粗对位 | 每集每角色一条；原位置大致接近，但不精确 | 核实集别与角色后，先建立 `mix-aligned` 粗对位基线，再利用粗位置和实际说出的内容逐句确认和精修。 |
| 3. 角色分轨、timing 完全错位 | 仍按角色分开；音频上的现有位置不可信 | 不用原位置推断目标句。按该角色最终台词，借助 ASR/强制对齐、词时间戳和上下文逐句找源片段；若跨集，先按内容确认集界。 |

mode 1/2 的“粗对位”只是**搜索线索**，不是对齐结果。三种 mode 找句时都必须同时使用日语 ASR/强制对齐与波形活动图，不能只选其中一种。找不到、重复录制、台本外反应声和角色不符时保留待复核记录，不猜测、不静默删掉。内容定位的证据要求见 [逐句源录音匹配](references/multimodal-source-matching.md)。

## mode 1/2：先 `mix-aligned` 建基线，再逐句精修

1. mode 1 先按内容确认集界，在安全静音处分集；mode 2 直接使用单集分角色音轨。核实每轨集别、角色和同步起点，不能把跨集长条直接送入 `mix-aligned`。
2. 对每集运行 `mix-aligned` 入口预检（时长、发声密度、跨角色重叠、台本粗时间），通过后在独立工作目录生成粗混基线，同时保留原同步角色分轨供后续剪辑。预检失败则先核查分集、集别、轨道同步和具体台词位置；不得用 `--skip-preflight` 强行生成基线，也不得把失败的粗混视作可交付成品。若经整理仍无法通过，转入逐句找源录音和排位，不因此跳过后续验收。
3. 以最终台本逐句比较基线中**真实发声开头**与目标开始码，并核对内容和安全切点。合格句保留原表演与位置；偏位句在角色分轨上安全重剪、移动，必要时顺延后归位，再合并全角色。粗混只用于快速建立位置和查找偏差，**不等于逐句对齐或正式完成**。mode 3 的源时间不可信，不先粗混，按内容逐句定位后进入共用流程。

## 三种 mode 共用的逐句剪辑流程

1. **建立目标清单。** 从最终台本导出逐句 `cue_id / episode / role / target_start / text`，保留原行号与来源。存在修订台词列时，非空修订文本优先，空白才回退原文；先核对列名，不能假定“最右列”或 D 列。只有字幕时，确认其角色和文字依据。目标清单是覆盖与验收基准，不因缺录而删行。
2. **用 ASR 与波形共同找全台词。** 先扫描整条演员源音频的波形/能量，建立全部发声区间清单；再运行日语 ASR、词级时间戳或强制对齐，确认每段说了什么并与最终台本逐句对应。把 ASR 词时间戳叠到波形上逐段核对：ASR 命中但波形前后仍有发声时，必须扩展或继续复核，不能按 ASR 起点截；波形有发声但 ASR 未命中时，必须听辨并归入台词、呼吸/表演声或经证实的 NG，不能丢弃。每句分别保存 `asr_alignment_evidence` 与 `waveform_evidence`，缺任一项不得进入计划。mode 1/2 从粗混基线逐句比对，已合格的句子也不能省略此核对。`source_active_start/end` 必须包住该句完整有效发声，包括 ASR 易漏的人名、称呼、短词、气声与尾音；每个目标 cue 恰好对应一次，全部波形发声也必须有归属。
3. **零截断切分。** 在真实静音/安全区选 `source_cut_start/end`，完整保留句首、尾音、呼吸和有效表演；切片余量不是发声本身。**切点处静音只是声学安全条件，不证明台词内容完整。** 确认 `source_active_start` 后，必须对演员源音频运行未归属波形活动审计：检查全部已规划发声范围之间，以及首尾至少各 2 秒内的明显声音段。任何波形发声没有被某个 cue 的 `source_active_start/end` 覆盖时，立即停止审计和渲染；先把它纳入正确 cue，或用绑定源文件哈希的审核表明确为 NG/废句/台本外内容。不能只因 ASR 从后半句开始命中，就忽略前面的声音段。句中长停顿、换气或 ASR 词间空白不能当作句首切点；句尾同理。不能按字幕结束码、固定时长或能量段数量切，不能靠 fade 掩盖截断。没有安全切点的连读保留为完整源单元，绝不硬拆。
4. **逐句放到目标时间。** 默认让**实际发声开头**对上该句 `target_start`，不是让带余量的切片开头对上。前句真实发声过长时完整保留，以 `normal_push` 仅顺延被占用的后句，并记录实际开头与差值；随后每句重新尝试回归自己的目标码，不把一次顺延平移整集。硬同步冲突、过大顺延或无安全切点而无法逐句归位时，标手动 timing/待复核，不截断、不变速。
5. **核对连续表演内部。** 一个完整源单元可以覆盖多个 cue，但只对齐它的首句**不等于**内部各句也对齐。仍须逐句记录内部真实开头、目标码和顺延解释；若无法满足或确认，整集不能标正式完成，只能交可调整的手动轨与问题清单。
6. **合并全角色时间轴，处理重叠。** 同集各角色先统一排位，再判断碰撞。台本时间框相交不等于剧情同时说话；回看成片视频和原声，确认是有意抢话才保留重叠。否则普通对白顺延，无法判断则待复核。
7. **渲染并逐集验收。** 每集核对目标清单全覆盖、逐句内容和真实开头、顺延/归位、源边界安全、重叠证据、音频格式与削波，并试听首尾、异常和中段。未实际试听不得声称已试听；任何未解决的句子使该集状态为待复核，而非“剪完”。先验收一集，再批量处理。

切点、顺延、重叠、格式和电平的具体门槛见 [音频技术规范](references/audio-spec.md)；这些数值是共同流程的安全门，不另构成来料 mode。

## 正式交付硬门槛

先在独立工作目录渲染，**重开实际输出音频逐句验收后**，才可写入项目的正式交付目录或称为“剪完”。排位表中的 `placed_start`、ASR/强制对齐候选、文件成功生成、峰值达标，都不能自行证明成品的真实发声起点；不得把计划值复制到 `actual_start` 充作成品复测结果。成品逐句复测的证据与记录口径见 [音频技术规范](references/audio-spec.md)。

每集必须全部通过：台本目标 cue 无漏、重、错角色或未核内容；每句同时具备 ASR/强制对齐证据、波形活动证据和内容首尾证据；演员源文件的全部发声区间均有归属，未归属波形活动审计为 `passed`；逐句成品真实开口与目标码一致，只有经核实的前句占用才允许记录 `normal_push`，随后能归位即归位；没有截词或未经确认的抢话；音轨、视频时长、格式和电平符合交付要求；并完成实际试听。**仅 ASR 命中、仅波形有声、仅切口为静音，任何一种单独成立都不算零截断通过。** 连读单元内部每句同样验收，不能只验首句。任一项未证实或未通过，整集状态就是**未完成**，不得用“待复核”替代通过、放进正式交付目录或向用户报告为已剪完。

无法听取音频、无法确认真实起点或遇到无安全切点的硬冲突时，保留源片段和逐句问题，说明阻碍并停止该集正式交付；不截断、不变速、不猜测。用户明确需要工作交接时，可在与正式交付物隔离的目录提供明显标注“未完成”的工作轨和 QC，但不能让用户承担本应由本流程完成的验收。批量任务只有首集通过上述硬门槛后才继续批量正式交付；其余集逐集独立过门槛。

## 交付形态

- 无真实重叠的集：输出一条整集对白 WAV。
- 确认有真实重叠的集：将参与重叠的角色**分别输出为独立同步音轨**，其他角色输出为一条混合音轨；各轨从 0 秒开始、样本数相同、增益口径一致。不要把两个重叠角色只合成一条给用户。需要试听总混时可另外生成，但不能替代这些交付轨。
- 未解决 timing 的正常轨/手动轨及独立待调句只是工作交接，标注未完成；不能冒充正式交付。
- 默认 48 kHz、立体声、PCM_24 WAV。优先遵循项目交付要求；本次 6600 项目沿用已确认的 -2.06 dBFS 整体峰值，不逐句归一化。

## 工具与权限边界

本 skill 的 `scripts/assemble_stems.py` 可用于建立匹配表、角色计划、全角色合并、边界审计和渲染；先用 `--help` 确认子命令参数。本机调用方式（Claude Code 每次 PowerShell 调用都是新会话，变量要写在同一次调用里）：

```powershell
$PYTHON = 'E:\AI_Models\envs\windows\speaker-evidence312\Scripts\python.exe'
$ASSEMBLE = 'C:\Users\zhao-\.claude\skills\dubbing-vocal-assembly\scripts\assemble_stems.py'
$FFMPEG = 'E:\AI_Models\RVC\RVC20240604Nvidia50x0\ffmpeg.exe'
& $PYTHON $ASSEMBLE <子命令> --ffmpeg $FFMPEG ...
```

整批渲染耗时较长时，用 `run_in_background: true` 运行。

`mix-aligned` 是 mode 1 安全分集后及 mode 2 的**粗对位基线入口**，不是 mode 3 的找句方法；其预检只说明若干声学条件成立，**不能证明逐句内容及起点正确**，不得把粗混直接作为正式交付。工具若只输出合并单元首句的对齐结果，必须另做内部逐句 QC；做不到就保持待复核。现有工具若不能直接产出所需角色分轨，需用经验证的剪辑/渲染方法补足，不得改变交付要求。

保留原录音、台本、字幕和成片视频，所有产物写到独立目录。不得自行覆盖或回写工作簿；若用户另行要求回写，先确认目标列与现有数据，尤其不能用固定 D 列覆盖修订台词。
