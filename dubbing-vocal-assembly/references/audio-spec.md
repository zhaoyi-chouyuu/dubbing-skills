# 音频技术规范：三种来料共用

本文件只规定逐句剪辑、放置和验收的技术细节。三种 mode 的定义与共同流程以 [SKILL.md](../SKILL.md) 为准。分轨时长、活动率、重叠面积或波形大致位置不能证明台词已精确对齐；`mix-aligned` 的四道预检不可替代逐句内容和起点 QC。

## 源音频定位与零截断

- `source_active_start/end` 标真实发声，不由字幕框、整秒数或固定 duration 反推。`source_cut_start/end` 标安全切点，两者不得混淆。
- 必须先扫描整条演员源音频的波形活动，再将日语 ASR/强制对齐的段落和词时间戳覆盖到波形上联合判断。ASR 决定文字候选，波形决定真实发声外沿；任何一方不得单独决定 `source_active_start/end`。候选片段数量等于台词数也不能证明匹配正确。
- 零截断必须同时通过两道门：①切点边缘声学安全；②该 cue 的最早/最晚有效内容已确认。第二道门用 `content_start_evidence / content_end_evidence` 记录；缺任一项即失败。切口静音、低边缘能量和 fade 都不能替代内容首尾检查。
- 候选 `source_active_start` 前必须回查到上一已确认源单元；首句回查到文件起点或已确认集界。跨度较长时至少先查 2 秒，发现发声则继续追溯。停顿前的语音若尚未分配给其他 cue 或明确标为 NG/台本外内容，该停顿不得用作当前 cue 的起点。句尾作对称检查。
- 人名、称呼、语气词、短词及非语言声须按实际读音核对。ASR 将人名转成片假名/近音或漏掉时，不能以 ASR 文本相似度为由缩短 `source_active_start/end`。
- 渲染前对源波形执行覆盖审计：默认以 -42 dBFS、10 ms 帧、80 ms 桥接、60 ms 最小活动段检查；在全部已规划发声区间之间及首尾各 2000 ms 内，任何未被 `source_active_start/end` 覆盖的活动都阻止输出。参数只可因已确认的录音底噪校准，不能为了消除漏检报警而任意提高阈值。
- 同一覆盖审计必须在生成逐句计划时先运行一次；计划中每条 cue 还必须分别记录 `asr_alignment_evidence` 与 `waveform_evidence`。缺列、空白、仅能量排序或仅 ASR 匹配一律不能进入渲染。
- 合法 NG/废句/台本外声音必须通过独立审核 TSV 豁免，字段为 `source_path / source_sha256 / start / end / decision / source_evidence / reviewed_by`；`decision` 仅接受 `ng_or_extra`，并须覆盖实际检测区间。属于当前或相邻台词的声音不能豁免，必须改正 cue 范围。
- 源发声前后通常各保留约 100 ms 安全余量；自动切分内部切点至少 80 ms。切点淡入淡出仅放在安全余量内，通常约 8 ms；不从字头淡入、不盖住尾音。
- 边界审计默认看切片首尾 40 ms；边缘高于 -42 dBFS 且未比活动区下降至少 12 dB 时，视为不安全并停止渲染。低能量通过也不等于已经确认无字音；只有 `content_start_evidence / content_end_evidence` 同时存在且可复核时，审计才允许通过。
- 相邻句没有安全静音谷时，保留完整连续表演或待复核；不能强切、变速、截尾，也不能用长 fade 掩盖切错。吸气、叹气、笑声、哭声、房间底和即兴反应不得被默认清除。

## 发声起点与顺延

- 每句默认以真实发声开头对齐其台本/字幕 `target_start`；带安全余量的切片可以更早进入时间轴，但不能冒充发声起点。
- 非故意重叠时，后句真实发声开头 = `max(target_start, 前面尚未结束的真实发声结束点 + min_gap)`。默认 `min_gap=50 ms`；安全切片余量不算台词占用。
- 每句独立重新计算，后续空档一旦容得下，就回到该句原始目标码。不得把一次顺延机械地累加到全片。
- 顺延达到 500 ms 记警告；超过 1000 ms 停止自动定案并复核。口型、动作或其他硬同步点若被占用，转手动 timing，不静默移动。手动 timing 也不能豁免内容匹配和安全切点。
- 连读源单元覆盖多条 cue 时，记录每条内部发声真实开头及目标差值；只验证整个单元首句，不能把内部 cue 或整集标成已对齐。

## 多人重叠

- 台本/字幕时间框相交、语义像插话或合并计划出现碰撞，都只是回看原作的线索。
- 核对成片画面、原声中第二人进入时刻及前后语境。确认为有意同时说话时记录集数、时间点、证据和复核者；否则按普通顺延。证据不足保留 `review_original`，不输出正式完成状态。
- 全角色计划先合并再处理碰撞。不能各角色独立顺延后盲混，也不能通过提高能量门槛、删轨或跳过预检消除报警。

## 输出与 QC

### 成品复测与放行

- 渲染后重新读取**实际输出音轨**，逐条记录 `cue_id / target_start / planned_start / measured_output_voice_start / delta / evidence / normal_push_reason / verdict`。`measured_output_voice_start` 必须来自对成品真实发声的独立检查，不能直接取排位计划值、源 ASR 起点或切片开头；波形、文本引导对齐和 ASR 只给候选，疑难句仍需听辨。连读单元须逐句检查，不能用单元首句代表内部所有句。
- 成品复测发现起点不符时，先回查源边界与切点，安全可拆则重剪；确因前句真实发声占用才记录必要顺延，后续有空档立即归位。未经证明的偏差、未确认内容、未验收重叠或不能安全拆分的连读均判该集 `not_ready`；不得通过改写 `actual_start`、降低检测门槛或只改文件标签使其通过。
- 放行前核对成品有效发声末尾及各轨样本数与视频/项目规定时长；不能为凑长度截断尾音，也不能无故附加静音使音频超出视频。未实际试听、QC 缺项或任一 cue 非 `pass` 时，禁止标 `ok` 或进入正式交付目录；仅在用户明确需要时另交隔离的未完成工作轨与问题清单。

- 默认 48,000 Hz、Stereo、PCM_24 WAV；项目明确的交付规格优先。6600 项目当前整体样本峰值目标为 -2.06 dBFS；其他项目须另行确认，不把此值硬编码成普遍标准。
- 保留演员相对动态，整集/共享总线统一防过载；不逐句峰值或 LUFS 归一化。只有实际存在 Music/Effect 输入且完成试听时才谈 ducking 或动态 EQ。完整节目 LUFS 不能当作对白分轨硬目标。
- 各正式输出轨使用相同时间原点、长度和共享增益；分轨之和应能还原试听总混，且无削波。
- 每集 QC 至少包含目标台本/字幕来源与哈希、全部 cue 的角色及内容匹配、源真实发声范围、安全切点、目标/实际发声开头及差值、顺延与归位、合并单元内部逐句状态、重叠依据、输出格式/峰值/削波、实际试听范围和未解决项。
- 任一目标 cue 漏失、重复、无可靠源匹配、被截断或内部 timing 未确认时，不得将该集写为正式 `ok`。批量任务须列明成功、待复核和失败的集数，不把部分完成说成全批完成。
