# 最终监督校对

在日语字幕生成/校对、语义排版和完整授权范围的 V26 全量时间首轮完成后、交付前执行。英语参考和日语底稿共用 [参考字幕引导听写与校对](reference-subtitle-review.md)；仅用户明确要求保留原时间码时跳过全量对齐。全量首轮完成后，字词/断句修订只重算受影响范围；不能以这一局部重算规则替代首轮全量。日语底稿听不清时保留原文，QC 标 retained_unverified 并继承原有疑点；文本保留和时间重对齐均不证明该句已听清。目标是用整片上下文发现模型和行级 QC 没抓住的问题；由负责交付的 Agent 完成语义判断，不能只运行规则扫描或再比较一次 ASR 就记为完成。仅修改技能时不启动媒体处理。

最终全文校对先确认可修复的长行/长段已完成换行与拆分，不接受仅扫描超限而未处理的版本；同时按 [动画字幕格式与翻译要求](subtitle-format.md) 检查成品排版、术语与画面字；区分普通对白、普通画面字、大幅画面字和同轴混合，逐条核对行数/字数、时长、CPS、间隔、标点、空格及重轴。新版允许大幅画面字3–4行及有记录的极限超限；日文画面字翻译可保留大意，但此许可不授权删改听录对白。同轴须画面字在上、对白在下，双人每行用 `- `，不可辨的众人齐声不用双人格式。格式限制不能成为漏掉可听台词的理由。

## 通读成品

按原片顺序读取实际 SRT 全部文本、字幕 ID 和时间，结合场景及前后对话理解。两路 ASR 一致的句子也要读。长片可按场景/连续区间分批，读取窗口带相邻对话，维护全片人物/术语及上下文笔记，记录已覆盖 ID；工具输出被截断时继续读取缺失部分。跨集一致性以本次提供/授权的素材为边界，不要求用户额外提供剧本才能开始。

检查专名异写、答非所问、否定/数字/动作或对象错配、代词与人物关系突变、语法断裂、短应答被并进长句、接缝重复及不对应当前场景的模板句。说话含混、争抢或多声部中出现荒谬句子要回查；幻想设定、玩笑、引用、说谎、方言、口吃和角色故意说错不能仅因“不合常理”被改掉。语义通顺也不能证明声音一致。

## 对照原字幕与听写前清单核对专名

按 [听写前人名与专有名词清单](pretranscription-glossary.md) 使用本次 ASR 前已保存的清单，逐条对照原日语字幕、OP/ED 画面文字及有出处的补充资料，覆盖所有交付行中的人名、地名、组织、技能、称谓与别名。检查是否误将声优名、角色标签或音效写入对白，是否把虚构词替换成常见词；记录异写、原文/选定字形、来源与输出 ID。来源冲突、身份不明或读音有歧义时遵守清单的保留规则，不用全局子串替换强行统一。

原日语字幕可以同时是“可靠的名称来源”和“仍需声音核查的台词底稿”。纯同实体字形可依据来源统一；语法、情节或声音仍可疑的台词不能因名词写对就标为全部已确认。

## 疑句回到声音核查

为疑点保留原句、候选、理由、字幕 ID 和源视频时间，提取覆盖完整发言及相邻对话的原音；边界吞字时扩大切窗。条件允许时先独立重听再比较候选，必要时用原视频画面辅助确定场景/实体。原音优先，BGM/重叠干扰时可试辅助人声或记录参数的重识别，不能把分离轨或另一轮模型输出自动当真值。

Agent 真正具备音频输入能力时可直接核查；否则通过实际支持音频输入的复核工具取得证据，明确谁/哪个工具听过什么片段。播放按钮、音频文件生成或文本候选本身不等于 Agent 听过。当前没有可用音频复核能力且证据仍不足时，保留具体疑点，不用“我听了”或“逻辑上应该是”作结论。纯字形统一可以依据已确认的同实体来源，但改变听写内容必须有相应声音依据。

全文逻辑校对发现的新疑点也纳入同一复核记录。遵守主流程每个疑点最多三轮追加复核的默认预算，避免相同音频/参数无限重试。对极短应答、否定和重叠保留各候选，无法判定时记 unresolved；不删除不清楚的句子、不填入更顺口的剧情猜测、不把怪句一概改成常见表达。已有日语底稿时，反复核查仍听不清就保留已匹配到同一发言的原字幕措辞，标 retained_unverified 并记 QC；原字幕即便逻辑可疑也不擅自润色。无对应原句则明确记缺失/未解决，不能虚构“原文”。不据英语意译或剧情猜测覆盖；已有推断/未解决项只有取得新证据后才能关闭。

## 修订与交付闭环

所有修改记录到 `review.jsonl` 的 final_editorial 阶段，更新日语文本版本与专名表；首轮 ASR 和修订前字幕保留。仅在 V26 模式下，改变词语/读音、补漏、删重复或改断句会使相关字符时间映射失效，回到受影响范围重新执行 V26 并检查邻句、覆盖及重叠。仅统一同音字形也检查字符数量/映射，必要时重对齐；不采用 Anime Whisper 的断句或时间。已有中文时使关联翻译失效并同步修订。

复读改动上下文并再查全片相关专名，直到无待处理的改动；随后保存最终 SRT，重查结构、媒体范围、全部单位的首轮对齐状态及必要的时间 QC，将最终文件哈希写入 `final_review.json`。记录全文阅读覆盖、真实音频核查范围和剩余不确定项，不把全文文本校对说成全片逐秒回听。SRT 正文不含未确认标签或审校备注；推断、未核实保留和未解决项逐条写入 QC。拆分后将所有疑点重新关联到实际交付的输出 ID 列表，保留原参考 ID 与历史。只接受完成上述闭环的版本；仍有实质疑点则 needs_review 并注明时间范围，不标成可直接用。
