# 最终监督校对

在日语字幕初步生成并完成 V26 对齐后、交付前执行。目标是用整片上下文发现模型和行级 QC 没抓住的问题；由负责交付的 Agent 完成语义判断，不能只运行规则扫描或再比较一次 ASR 就记为完成。仅修改技能时不启动媒体处理。

## 通读成品

按原片顺序读取实际 SRT 全部文本、字幕 ID 和时间，结合场景及前后对话理解。两路 ASR 一致的句子也要读。长片可按场景/连续区间分批，读取窗口带相邻对话，维护全片人物/术语及上下文笔记，记录已覆盖 ID；工具输出被截断时继续读取缺失部分。跨集一致性以本次提供/授权的素材为边界，不要求用户额外提供剧本才能开始。

检查专名异写、答非所问、否定/数字/动作或对象错配、代词与人物关系突变、语法断裂、短应答被并进长句、接缝重复及不对应当前场景的模板句。说话含混、争抢或多声部中出现荒谬句子要回查；幻想设定、玩笑、引用、说谎、方言、口吃和角色故意说错不能仅因“不合常理”被改掉。语义通顺也不能证明声音一致。

## 仅凭成片建立专名表

- 将可辨认的人名、地名、组织和作品内术语按实体记录读音、出现位置、候选写法、选定写法与依据。片内画面字、片头/片尾及明确可对应的文字可帮助确认字形；须实际查看并确认对应关系，不能仅因某个汉字像名字就采用。
- 相同实体前后保持已确认写法，但保留姓/名、昵称、敬称、别名以及剧情中的改名；同音不同实体不可误合并。批量替换前逐项检查出现语境，不用子串替换误伤普通词。
- 音频可确认读音而无法确认汉字时，暂用与证据一致的假名并在记录中标明字形待定，不能凭常识或剧情猜定汉字。此前已确认写法与新声音冲突时回查，不为保持表面一致而掩盖错误。没有证据时记录不确定性，不要求不存在的参考剧本。

## 疑句回到声音核查

为疑点保留原句、候选、理由、字幕 ID 和源视频时间，提取覆盖完整发言及相邻对话的原音；边界吞字时扩大切窗。条件允许时先独立重听再比较候选，必要时用原视频画面辅助确定场景/实体。原音优先，BGM/重叠干扰时可试辅助人声或记录参数的重识别，不能把分离轨或另一轮模型输出自动当真值。

Agent 真正具备音频输入能力时可直接核查；否则通过实际支持音频输入的复核工具取得证据，明确谁/哪个工具听过什么片段。播放按钮、音频文件生成或文本候选本身不等于 Agent 听过。当前没有可用音频复核能力且证据仍不足时，保留具体疑点，不用“我听了”或“逻辑上应该是”作结论。纯字形统一可以依据已确认的同实体来源，但改变听写内容必须有相应声音依据。

遵守主流程每个疑点最多三轮追加复核的默认预算，避免相同音频/参数无限重试。对极短应答、否定和重叠保留各候选，无法判定时记 unresolved；不删除不清楚的句子、不填入更顺口的剧情猜测、不把怪句一概改成常见表达。

## 修订与交付闭环

所有修改记录到 `review.jsonl` 的 final_editorial 阶段，更新日语文本版本与专名表；首轮 ASR 和修订前字幕保留。改变词语/读音、补漏、删重复或改断句会使相关时间映射失效，回到受影响范围重新执行 V26 并检查邻句、覆盖及重叠。仅统一同音字形也检查字符数量/映射，必要时重对齐；不采用 Anime Whisper 的断句或时间。已有中文时使关联翻译失效并同步修订。

复读改动上下文并再查全片相关专名，直到无待处理的改动；随后保存最终 SRT，重查结构、媒体范围和必要的时间 QC，将最终文件哈希写入 `final_review.json`。记录全文阅读覆盖、真实音频核查范围和剩余不确定项，不把全文文本校对说成全片逐秒回听。只接受完成上述闭环的版本；仍有实质疑点则 needs_review 并注明时间范围，不标成可直接用。
