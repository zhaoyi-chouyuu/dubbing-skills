# 参考字幕引导听写与校对

英语和日语参考使用同一套处理步骤，只切换参考文本的用途。保留主技能中的 WSL 优先、默认 Anime Whisper 单模型听写（明确要求时才用双模型独立解码）、全音轨查漏、人名清单、局部回听/分离、OP/ED 排除、格式规范和 Agent 最终全文校对。

## 选择参考与记录来源

原日语字幕通常较可靠，但不能假定全部正确；专名按来源清单核对，台词修改须有声音证据。识别同一作品/集数、当前视频版本的参考字幕，记录 `reference_language=en|ja|none`、路径、SHA256、原始 cue ID、文本、时间及来源。日语和英语均有时，日语作底稿，英语辅助；不要仅凭文件名把不同剪辑/集数混用。时间模式默认独立记录为 `timing_mode=v26`，并记录 `timing_source`、全量范围和模式选择依据；文字参考可靠不表示原轴应保留。

默认在文字、补漏和断句处理完成后，对完整授权范围的全部对白执行 V26 重对齐，包括旧轴曾获确认的行。客户反馈同进同出、人物分轴或整季 timing 问题时按反馈授权范围全量处理，不能只改样例或报警条。旧字幕时间仅辅助找原音，不锁定最终起止；最终画面字范围须按视频帧逐项核对。只有用户明确要求“只改文字/保留原轴”时使用 `timing_mode=trusted_reference` 并记录原话，不因存在日语/英语参考自动选此分支。

## 同一流程，不同参考文本

1. 按 [听写前专名清单](pretranscription-glossary.md) 从原日语字幕、OP/ED 画面文字等建立并保存本次人名/专有名词清单，再启动识别；读取已有 QC，记录实际 OP/ED 音频排除范围。保留原字幕副本。继承原稿的推断、缺失和未解决项；不因原字幕可加载、ASR 一致或原文被保留而关闭它们。
2. 按参考块定位音频，前后留上下文；可联合听相邻块，避免在句中硬裁。默认由 Anime Whisper 听写声音；明确启用双模型时两路独立解码，不向首轮 ASR 提供参考台词或英语反译，再由 Agent 将结果与字幕逐块比对。ASR 候选不是声音真值；双模型时也不以多数票判断，Anime Whisper 不参与字幕断句或 timing。
3. `en` 分支：英语作句意和覆盖清单，听写实际日语。结合可辨发音、英语和上下文消歧、选最佳候选，推断记录 `inferred`，仍不能确认则 `unresolved`；纯反译不能当已听清原话。完全没有可支持的日语候选时保留能确认的部分；整块无可用文本则在 QC 明确记缺失，不用占位或编造台词凑齐输出。
4. `ja` 分支：现有日语是底稿，独立听写用于检查是否与声音有出入。明确听清且确认原文有误时才改字、补漏或删重复；记录原文、改文及声音证据。听不清、证据不足或模型冲突时保留原字幕措辞，状态写 `retained_unverified`，原有 `inferred/unresolved` 状态继续保留。QC 写出原文、ASR 候选、时间、问题及回查结果；不根据英语语义、模型多数票或剧情推断覆盖底稿。格式换行/拆块可继续执行，不能以排版为由改写原话。
5. 两种分支均逐块查否定、数字、人名、漏句、重复和重叠对白，并检查参考块以外的音轨。发现参考遗漏且声音可确认的台词应补回并记录新 ID 与来源；补句先记录原音粗范围，最终 timing 与其余对白一起进入全量 V26；首轮后新增补句才局部重对齐。声音或时间仍不明确时记 QC，不能静默漏掉或编造精确锚点。每个疑点追加复核默认最多三轮，复用原声、用户提供的干音及缓存，必要时局部分离。全量对齐首轮后的疑点复核不反复重跑整片。
6. 对照原日语字幕和本次清单核对所有人名/专有名词，完成字幕格式处理及完整范围的 V26 首轮对齐，再由 Agent 通读全文与改动上下文，检查文本逻辑。逻辑可疑处回查原声；最多三轮追加复核仍不清楚时保留对应的原日语字幕，记 retained_unverified，即使原句仍可疑也不猜写。无对应原文时记录缺失/未解决，不能虚构回退文本。交付日语 SRT 和独立 QC，不逐块等待用户确认才继续。

项目清单中已确认同一人物的纯同音字形可统一；身份或读音仍有歧义时，日语底稿保持原写法，仅记录待核。保留称呼、昵称和敬称，不能见到清单就凭剧情替换。

## 全量 timing 对齐与长字幕拆分

默认保留完整台词及源/输出映射，按原音确认发话顺序和人物交接，不沿用旧的错误断句与起止。先在自然短语处换行，使普通对白每条最多2行、每行≤14字符（含标点和空格）、通常总计≤28字符；仍过长或显示超过7秒时拆为多条。全部对白经 V26 对齐后映射回这些字幕块，不能以“原轴可信”跳过首轮。

拆分须有语义与声音依据：全量 V26 字符对齐、原音停顿与实际交接共同确定内部切点；仅在明确选用 Turbo 时，其词时间才可作待核候选，禁止按字数平均分时或沿用 Anime Whisper 块边界。旧 cue 的外层起止不限制新结果；核对并记录新起止、源 cue 到输出 cue 的一对多映射、所用声音边界及回退状态。仅在用户明确保留轴的分支中，才尽量保持源段外层范围，并在必要时局部对齐。没有可靠边界时复核并记具体未解决项，不伪造对齐成功。

检查实际视频帧率，字幕之间至少一帧间隔。只做有依据的必要显示时间调整，保存修改前后时间，不能盲目统一裁尾、跨入下一句或挪走已确认发音来满足指标。短应答不足0.8秒但无法安全延长时，保留原声音范围并记例外。CPS≤12、目标5–7；拆分不能降低整段本来过快的语速，不靠删字或错轴凑指标。

## 独立 QC 与交付核对

SRT 正文只放台词与规定的画面文字，不加入「聞き取り要確認」「听不清」「待核」、置信标签、替代缺字的省略号或审校备注。真实台词和停顿符号不在此限制范围。

每项 QC 包含参考语言、源字幕路径/哈希、源 cue ID/原时间、原文、对应输出 ID 列表、最终文字、本次已启用的 ASR 候选（未启用第二路时不要求第二路字段）、证据、采用/保留理由、回查方式、状态及继承的旧疑点 ID。拆分后旧 QC 必须重新映射到当前输出 ID；不能让报告指向上一版序号。

区分 `confirmed`（有证据核实）、`inferred`（英语分支的推断）、`retained_unverified`（日语底稿因无法听清而保留）和 `unresolved`（仍未解决）。日语底稿保留且有继承疑点时同时保留旧状态，不改成 confirmed；单模型多次一致或已启用双模型的一致也不自动证明正确。字幕能播放与内容已全部核实分别记录，实质疑点未解决时整集仍为 needs_review。

逐项核对全部源块的输出、拆分、合并、排除和缺失映射，包括未能识别的第二说话人。默认检查每个应交付发话单位都有 V26 首轮匹配、失败或回退记录；旧轴未改数值不能视为漏跑，但必须有本轮处理证据。逐条检查声音依据、上下文、间隔及画面字的实际可见范围；保留轴分支另核对无改时块与源时间一致。不能只靠字幕框覆盖率证明无漏句，或用超限清单替代可修复的格式工作。保存实际交付 SRT 哈希，最终回复给出字幕和 QC 路径。
