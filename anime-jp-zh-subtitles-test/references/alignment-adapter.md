# 本机精对齐适配约束

当前可用基础是 `subtitle-align-skill-gpu` 的 V26，不是原稿 Mac 的 `subtitle-alignment-jp/scripts/align_single.py`。这里说明复用边界，不声称新联合对齐适配器已经实现。

WSL 入口：`/home/zhaoyi/.openclaw/workspace/master_aligner_v26.py`。调用前检查源码与签名，以实际安装版本为准：

- `align_one(audio_path, srt_path, output_path, vad_mode="hybrid")`：自带 Phase 0 结构预处理；返回原字幕、结果、波形、采样率、字符时间线与 VAD 岛。
- `quality_check_and_autofix(...)`：会修改结果并覆盖输出，不是只读 QC 接口。旧版本会因 WHISPER_EMPTY/SILENT 将字幕缩到 0.5 秒；本实验不得把这种操作当作复核结论。可在隔离副本上分析报告并拒绝启发式改时，或写只读 QC 适配器。

不要直接修改正式引擎来试验。为新适配器保留源版本/哈希、独立路径与验证记录；缺少必要能力时阶段记 blocked_dependency/needs_review。

## 可信文本和粗定位

先从双路及声音证据确认日语。乱码、异常重复、疑似截断、候选不对应声音时返回听写复核，不能强制挤入一段音频。不要把旧稿按固定字数硬切，再按字数平均分配的时间当精确锚点。

粗定位来自 Turbo 主路原音窗口/segments，经声音核对后使用；Anime Whisper 仅审查文字，其标点、生成块、窗口及词时间不作为断句或 timing 依据。断句结合确认文本的语义、原音停顿和说话人交接；Turbo 的原生分段也不是最终字幕块。

最终 timing 采用既有 V26 方法。句内边界只是估计时，将连续确认的日语合并为有外层粗定位的短语音块；记录已确认字幕块 ID 到字符的映射，联合对齐后拆回字幕。因 Anime Whisper 审查而改字、补句后，重新对受影响文本进行 V26 对齐，不复制它的时间。对齐失败保留粗范围及失败标记，不能用 fill_unmatched_timings 的估计冒充匹配。

## 波形归一化与时间映射

读取选定日语 wav2vec2 模型的 `preprocessor_config.json`。若 `do_normalize=true` 且底层模型调用绕过处理器，则对实际送入模型的每个独立音频窗口作对应零均值/单位方差归一化。优先使用该模型真实 feature extractor；明确其是否返回 padding、attention mask 和采样率要求。

若复用的 WhisperX 路径直接将 raw waveform 喂给模型，不能假设它调用了 feature extractor。适配时可把一个外层确认窗口裁出，在其本地时间上合并文本并对齐；应对相同的真实有效样本（不含补零）归一化，避免全片一次归一化后又裁窗。不要再重复归一化已经处理过的波形。

对齐前后保留：源视频时间、裁剪音频偏移、窗口内字符时间、映射回原片后的时间、置信/匹配和回退信息。内部模型 padding 不产生新的音频时间。时间映射通过源轨 PTS/剪辑记录计算，不能默认第一段音频就是视频零点。

## 外层保护和验收

- 原窗口首尾可提供保护范围与上下文；窄句框不能约束对齐器去“证明”猜测的句内时间。时间超出可信外层范围、被异常压缩或拉伸时，回到联合复核。
- 核对匹配字符是否与对应音频区域相容，不能仅以字符匹配率高判正确；检查短词、否定、数字、专名、相邻接缝。
- 保留真正的重叠对白与短应答。背景音乐/拖音中的 VAD 不是对白边界真值；歌曲不用对白裁尾规则。
- 全音轨漏句检查与对齐行级 QC 两者都要做。写出可解析、无意外重叠的 SRT 仅是文件结构检查。
- 中文从经确认的日语和映射产生，不作为日语对齐模型的输入。
