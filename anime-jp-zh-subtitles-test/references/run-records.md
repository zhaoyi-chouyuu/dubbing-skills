# 运行记录与验收

实际试跑前读取。每次建立独立 `run_<本地日期时间>/`；用户指定成品位置时遵从指定位置，原始输出和证据留在运行目录。保存技能、预检依赖、运行媒体是三个不同阶段。

## 时间模式与项目清单

分别记录 `reference_language=en|ja|none` 与 `timing_mode=v26|trusted_reference`、`timing_source`。默认 v26；仅用户明确要求保留轴时使用 trusted_reference，保存该指示。记录源字幕路径/哈希、原 ID、原始时间/文字、对应输出 ID、最终文字、内容状态及 timing 匹配/回退状态；记录纳入、OP/ED 音频/歌词排除、指定画面字纳入、拆分/合并、补漏与缺失。默认全量首轮须逐集核销授权范围全部应交付发话单位，不能因原轴可信或 QC 未报警标 skipped。旧 cue 时间与输出时间都保存，但不要求默认 V26 新结果停留在旧范围。画面字逐项记录当前视频帧证据。只有显式保留轴分支的全量阶段可标 skipped_explicit_user_preserve_timing；必要局部对齐另记。可修复的换行和超长段必须处理，不能只列超限。

本次 ASR 开始前保存专名清单及可读版本，记录保存时间/版本和实际来源；详见 [听写前专名清单](pretranscription-glossary.md)。来源包括原日语字幕、OP/ED 画面文字及用户项目清单；PDF 台本另记来源类型。记录字幕 ID/原时间、画面时间/截图或台本页码、源路径/哈希、读音、别名及冲突。明确项目约定优先，外部资料仅补缺。疑点只写 QC，不向 SRT 注入占位或审校标记；推断候选不能标 confirmed。英语分支无可用日语候选的缺失块必须留在逐块记录与 QC 中，不能用空 cue 或编造台词凑覆盖率；日语分支听不清时保留原文，记录 retained_unverified，并保留旧 QC 的 inferred/unresolved 状态、来源与疑点 ID。拆分后更新 QC 对应的实际输出 ID 列表。详见 [参考字幕引导听写与校对](reference-subtitle-review.md)。

## 最小记录

- `manifest.json`：源路径、字节数、SHA256、时长、视频与音轨的起始时间/时基、所选音轨、采样率、测试区间、提取命令、目标语言、运行范围及授权。记录每段原片起止、提取音频起止和两者映射。偏移不是必然为零；片段相接处也不一定连续。
- `models.json`：两路仓库 ID、revision、实际本地路径、权重身份/哈希、Python/库版本、设备、精度、加载和推理阶段状态。标明 ASR-A 为 Turbo 主稿、ASR-B 为 Anime Whisper 文本审查；两者同属 Whisper 系。无法确认的 revision 写 unknown，不能由文件夹名称推断。
- `asr_a/raw.jsonl`、`asr_b/raw.jsonl`：实际处理的源音频窗口、样本索引、重叠长度、模型参数、原始日语及原始返回值/分数。没有分数时写 null。时间粒度分别写 `chunk_only`、`segment` 或 `word`，不能补造词级时间。
- `coverage/`：全时轴 VAD/能量或音频事件结果、两路窗口与字符覆盖、负区间复扫记录。列出所有区间，包括两路空白且 VAD 阴性的区间。
- `segments.jsonl`：稳定 ID、原始候选及窗口 ID、日语文本版本、音频范围、断句理由、V26 对齐和其他声音边界证据、匹配与回退状态，以及确有依据的说话人/冲突信息。普通字幕不要求身份标注，说话人可为 null，不为填字段启动声纹处理。Anime Whisper 窗口只记录审查出处，不列为断句/timing 证据。
- `review.jsonl`：疑点 ID、类型、上下文音频路径、每轮方法/参数/独立候选、采用或拒绝的证据、理由、状态；每项默认最多三轮。最终全文校对发现的问题标记 `phase=final_editorial`，保存原文/改文或保留原文的理由、继承疑点 ID、源/输出 ID 列表、专名关联、实际回听者/工具和能力、时间对齐复查结果。允许未解决并继续别的区间。
- `glossary.json` 和 `人名与专有名词清单.txt`：每次听写前保存，可复用核实后的来源快照；本次素材内的人名、地名、组织及专属术语，包含实体 ID、读音、观察到的写法、选定写法/待定状态、出处字幕 ID/原片时间及证据；保留昵称、敬称和同音不同实体，不盲目全局替换。跨集仅在本次授权素材范围内复用。
- `alignment_coverage.json`：授权集数/区间、全部应交付发话单位 ID、实际对齐输入文本哈希与源音频范围、输出新起止、匹配/失败/回退状态及证据路径；另记画面字逐项核时结果。逐项核销，无处理记录为 incomplete，不用文件数、字幕哈希或结构通过替代全量对齐证明。保留轴分支写明用户指示、跳过范围及必要局部处理。
- `final_review.json`：负责交付的 Agent 对全文实际阅读的顺序/分段与字幕 ID 覆盖、各文本版本、术语一致性结果、逻辑疑点及处理、最终局部复读和对齐/结构检查结果、字幕格式规范来源/版本/哈希，区分普通对白、普通画面字、大幅画面字和同轴混合的行数/字数/时长/CPS/间隔/标点/重轴核查，以及画面字精简的原文/译文/理由与例外记录、剩余问题、最终交付 SRT 的哈希和阶段状态。全文指所有交付行，包括 ASR 一致或 QC 未报警的行；不等同于全片逐秒人工回听。仅统计覆盖不能证明语义正确，不得用自动标记代替阅读。
- `translation.jsonl`：仅在用户要求中文时生成，记录中文、所依赖的日语版本与源片段 ID；日语发生修改时标记关联中文失效，重译后更新。
- `output/`：默认仅日语 SRT，质检后复制到用户指定位置，默认源视频同目录 `<视频名>.ja.srt`；简体中文 SRT 和日中映射仅按需生成。有未解决问题时文件名或报告明确 draft/needs_review，不标“可直接用”。字幕结构检查结果与音频质量验收分开保存。
- `report.json`：阶段耗时、实际跑过的能力、缺失能力、人工/有音频输入的复核来源、剩余疑点、对齐失败与估计回退数量、最终全文逻辑校对的完成情况和整批状态。默认记录 voiceprint.enabled=false、voiceprint.status=skipped_by_config；未建库不列为字幕阻碍。可选步骤实际启用时另记范围、收益和额外耗时，区分模型加载、主处理与疑点复核，不凭短测速承诺整片时间。

音频片段引用至少含媒体哈希、原片开始/结束秒、重采样后的样本区间。缓存键还须包含模型 revision、参数、文本版本；恢复时拒绝沿用不匹配的旧结果。

## 验收判定

1. 本次人名/专有名词清单已在 ASR 前保存，原字幕与 OP/ED 画面来源或缺证状态可追溯；OP/ED 画面取名不意味着纳入歌词。所选范围全部时间均有处理/待查状态。正片范围内的对白、歌曲、无字声音和两路共同空白均不能因未生成字幕而消失；OP/ED 音频与歌词默认排除，记录各集实际起止及排除范围；另逐集验收作品名、原作出处、出品方/版权信息及每话话数/标题等指定画面字的实际纳入情况，保存画面证据、显示范围和输出 ID。素材未出现或无法辨认时记录缺项原因，不编造补齐。
2. Turbo 主路与 Anime Whisper 文本审查独立转录并保留首轮；不要求不同模型体系，也不将同系一致称为独立正确性证明。共同空白、否定、数字、人名、短应答和接缝均有检查记录。
3. 默认完整授权范围的全部应交付对白已执行 V26 首轮，逐项记录实际处理与匹配/失败/回退；仅用户明确要求保留原轴的范围可例外跳过。进入精对齐的文字与原音有对应证据；尚听不清而保留的底稿继续继承内容疑点，高匹配分不关闭它。断句不依赖 Anime Whisper，原粗定位、估计句内 timing、V26 字符匹配及失败回退明确区分；画面字按当前帧核时。全量完成指全部项有处理结果，不表示全部匹配成功；有实质失败/疑点仍为 needs_review。
4. 检查正时长、媒体范围、时间映射、文本/ID 保持情况；对白与对白、画面字与画面字不重轴，画面字与对白可以重轴；同一帧两人对话按格式合为同一字幕块、每人一行并加行首连字符。保留真实说话内容，无法满足时记录限制，不强行删除或改写。
5. 日语 SRT 覆盖用户要求的完整视频或明确指定片段，并按 references/subtitle-format.md 核查普通对白最多两行、通常总计28字符、每行14字符（含标点与空格）、0.8–7秒、至少一帧间隔、CPS≤12（以5–7为宜）、标点/空格、断句和屏幕文字；大幅画面字允许3–4行，日文画面字翻译可保留大意并记录极限超限理由，不按普通对白一刀切报错；同轴上画面字下对白、双人 `- `、不可辨齐声不套双人格式等按新版逐项验收；歌曲与未解决项状态明确。最终回复突出日语成品路径，不用原始听写或 JSON 替代字幕交付。若要求中文，其内容须与当前日语版本对应，没有声音依据的日语不能翻译成确定的中文台词。
6. 负责交付的 Agent 已实际通读全部日语字幕并校对上下文逻辑及专名一致性，包含两路共同出错的可能；疑点有音频/画面来源或明确未解决状态。已核实全部应交付单位的全量首轮记录（或显式保留轴指示）；首轮后文字修订已完成受影响范围的必要局部对齐、长段拆分及相邻边界复查，并完成实际交付版本的最终检查，校对记录指向相同文件哈希。未完成此阶段不能报告可直接使用。

状态：`auto_passed` 仅代表通过明确记录的自动检查；实质疑点未解决为 `needs_review`；关键模型/接口缺失为 `blocked_dependency`；已执行阶段发生无法恢复的错误为 `failed`。允许分阶段状态：例如 skill 结构 validated，而双 ASR 尚 blocked，不能合并写成试跑通过。

无可信独立参考时，只报分歧、未解释语音时长、修复/回退数量等代理指标。不要报告真实漏句率、准确率或毫秒级时间精度。模拟/静态检查也不能报告为真实视频成功。
