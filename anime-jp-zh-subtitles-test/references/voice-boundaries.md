# 声纹与说话人交接点

仅在用户另行要求角色标注/身份一致性或明确启用声纹实验时读取执行；普通日语 SRT 默认跳过，不检查资源、不建库、不运行匿名声纹聚类或多模型集成。跳过不是依赖缺失或质量失败。声纹是可选的身份/边界支持证据，不能替代全音轨听写、字词对齐或重叠语音分离。

## 效率优先的启用范围

先说明要解决的具体角色身份问题。优先使用已有可靠样本与单个可用模型，仅处理相关区间；不默认启动全片 CAM++／ECAPA512／ResNet34 三路集成或重建整库。记录加载、特征提取、匹配和复核耗时，以及实际消除的疑点；收益不足或超出用户时限时停止扩展，回到常规 V26 与局部声音复核。不要未经测量声称本阶段耗时可忽略或必然大幅提升字幕准确度。

## 先确认能力和样本

- 仅检查本次选用声纹模型的真实权重、入口、采样率及运行环境；可参考已安装的 `dubbing-script-preparation` / `dubbing-script-automation` 的声纹资源位置，不因此启动完整配音台本流程。仅发现模型文件夹不能标记已加载或已测试。
- 不同模型的嵌入维度、归一化与分数不可直接混算。保留各路原始分数、参考样本 ID、模型版本与实际阈值，阈值须校准，不能将余弦分数当正确率。
- 命名角色样本必须有可靠的角色对应、原片时间来源，且相对干净、无重叠。可以用多个可信样本覆盖情绪/音色变化；不能用当前未解决台词循环自证。
- 缺可靠命名样本时不自动建库或转跑全片匿名聚类；若当前启用范围允许局部匿名候选，使用 `speaker_01` / unknown 等标记，说明命名主角声纹库效果尚未测试。只有部分能力可用时保留阶段限制。

## 边界融合

1. 对原音的说话范围和交接候选做粗定位，含 VAD 阴性但其他证据提示的短声音。
2. 用邻近可信声音窗口计算声纹身份支持，记录低置信、不同模型冲突和 unknown。
3. 联合词/字符时间、停顿和实际处理窗口检查交接点；必要时提取带前后文的原音，交给确有音频输入能力的复核工具。
4. 只有证据支持才修改字幕边界。记录原边界、新边界、声纹样本/分数、词/字符证据及复核结论。

不要将窗口中点、最近的 VAD 岛或最高相似角色直接设为精确切点。不要强迫所有声音归入已有角色。主角连续独白主要依赖文本对齐；极短应答、情绪音色变化、笑/叫声、同时说话单独列疑点。

确需拆合字幕时保存源 ID 和日中版本映射；改时本身不改文字。重叠对白保留双方时间范围；需要 ASS 分层时说明与 SRT 的展示差异。阶段失败可继续已确认的文本处理，但不得宣称完成声纹辅助边界验证。
